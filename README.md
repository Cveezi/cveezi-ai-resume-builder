## About Cveezi

[Cveezi](https://cveezi.com/) is an AI-powered resume builder designed to help job seekers create professional, ATS-friendly resumes.

With Cveezi, users can:
- Build professional resumes.
- Improve resume content using AI.
- Create ATS-friendly CVs.
- Improve their job application process.
